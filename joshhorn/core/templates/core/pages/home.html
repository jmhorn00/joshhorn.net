About

Hey, I'm Josh

I'm a software developer with a passion for building clean, practical web applications. My work centres on Python and Django on the backend, paired with modern HTML, CSS, and JavaScript on the front — always prioritising simplicity, performance, and good user experience.

I enjoy the full journey from rough idea to deployed product: architecting data models, wiring up APIs, crafting responsive interfaces, and shipping something that actually works well for real people.

When I'm not writing code, I'm probably tinkering with a side project, exploring new tooling, or thinking about how to make something a little more elegant.
